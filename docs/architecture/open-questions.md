### Q18 — Prevent predictable Adaptive shortages — DECIDED; PROOF PREPARATION

[The approved contract](decision-register.md#adaptive-bank-sufficiency-direction) permits incomplete drafts but forbids executable publication without sufficient eligible distinct questions for every supported selection path to its normal stop. D25 may require twenty, not only five, and the global bank count is not proof of eligible supply. Revalidate applicable participant-specific dynamic eligibility before start without partial attempt/allowance on rejection. Keep the immutable bank/policy fixed; later publication cannot supply an active attempt.

The author explicitly configures permitted lower/higher reserve levels and their preference order; use them only after genuine requested-level depletion. Preserve other topic/access/repeat/exclusion rules, grading weights and D25 evidence boundaries. No global fallback distance/direction/order default or cross-quiz/Learning selection input is introduced. Author diagnostics name the insufficient level/topic/reserve with useful bounded counts.

**Example:** two questions can be saved as a draft today. Publication still fails if a reachable level/topic lacks sufficient permitted questions, even when the bank has twenty in total. Properly configured reserves can resolve that only if every supported path is sufficient. The learner never starts a predictably understocked assessment.

The proof/admission algorithm and conformance fixtures are engineering preparation, not an arbitrary exhaustive-algorithm requirement. Validation cannot prove storage corruption or implementation failure impossible; [exceptional recovery](#oq-r15) remains separate. No ordinary shortage terminal result, invented pass/zero, allowance refund or mutable substitution is approved.
